# Vanilla · Reference-textured roster

This is a complete retail movement profile with 35 character entries and the original Jedi Knight weapon attachments. Indexed also supports the software renderer.

Choose one ZIP. Accelerated has RGB565 world textures, and Indexed has palette world textures. Extract its named folder beside JK.EXE. From that directory run the following command.

    JK.EXE -path RedRosterPhoto

Five bodies have revised materials: Red’s T-visor, red-visor and crown-braid Mandalorians, Biddy Blas and Lilivane. The geometry and animations come from the verified seven-character hand-and-elbow builds. Biddy and each Mandalorian draw one full-detail mesh set at every distance. Lilivane carries the same 14,051 polygons, including their UVs and materials, in all four geometry slots. Both of each character’s hands are attached to the body. The T-visor has the repaired upper sleeves on both arms. Darth Lilitari and the T-800 Hybrid use their previous materials. The original equipped weapon models and Kyle’s fist stay on their game-specific routes.

The Mandalorian paints use the front and rear images retained in each Tripo project. Lilivane uses the front, left and back views supplied to Tripo, the matching turnaround and its larger face study. Her wings keep the original translucent faces. Red credits Andrei’s Tripo generation for Biddy’s R3 game body. The review folder records which Biddy source images were recovered and how they were applied to the current nine UV atlases.

Character models and earlier revisions by Red with Andrei. Integration, rig fitting and reference-guided materials by Coda with Andrei. Saber Battle X 3.1 by ShadowX and its credited contributors. For private review on an owned installation of Jedi Knight: Dark Forces II.
